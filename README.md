# CineFilm & TV - Web Portal & CRM

Portale web dedicato a recensioni, approfondimenti e trailer per cinema e serie TV, completo di pannello CRM per la gestione dei contenuti.

## 🚀 Dipendenze del Progetto

### Frontend
- **Bootstrap 5.3.2** (Interfaccia UI e layout responsive)
- **FontAwesome 6.4.0** (Set di icone)

### Backend / Server (Node.js)
- **Express.js** (`^4.18.2`): Framework HTTP per route e API RESTful.
- **pg** (`^8.11.3`) / **Mongoose**: Client Database.
- **dotenv** (`^16.3.1`): Gestione delle variabili d'ambiente.
- **cors** (`^2.8.5`): Abilitazione per chiamate cross-origin.
- **jsonwebtoken** (`^9.0.2`): Autenticazione JWT per la dashboard CRM.
